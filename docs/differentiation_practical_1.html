7  Gene regulation in time

Introduction

In this practical you will get hands on experience into making gene regulatory networks models. First you will practice how to encode regulatory interactions into ordinary differential equations and logical rules. Next you will use an example Boolean network and will recover its self-sustained activity configurations (attractors). Lastly, you will learn how to predict the genes that cause cell fate transitions (attractor changes).

Today we will use the following python file: WC07_Gene_regulatory_networks_I.py. In it you will find the parameters, functions and execution code. Throughout the practical you will find new code in drop-down menus. Look at what each function takes as input and returns as output. You need to add them in the #Functions part of the code, and remember to use them in the #Execution part.

7.1 Regulatory interactions

In the main you have a Boolean and an ODE model to simulate an \(AND\) gate where the variable \(A\) and variable \(B\) are both needed to positively regulate \(C\). This could represent that \(A\) and \(B\) are transcription factors that form a protein complex, and that it is via this complex that they can bind the promoter of \(C\) to promote its expression.

While ODEgeneRegulation() encodes this regulation with an ordinary differential equation that requires several parameters, logicalRule() only needs the logical operator relating the input genes.

ODE implementation

\(\frac{dC}{dt}=p\frac{A^n}{K^n+A^n}.\frac{B^n}{K^n+B^n}-dC\)

Where \(p\) is the production rate, \(K\) is the half saturation constant (represents the affinity of a TF to the promoter), \(n\) is the cooperativity of transcription factor binding, and is the same for \(A\) and \(B\), \(d\) is the decay rate.

Logical rule implementation

\(C_{t+1}=A_t\) & \(B_t\)

Running the code will produce a plot showing the value of \(C\) for different combination of values of \(A\) and \(B\). Both implementations of this regulatory interaction produce qualitatively the same effect, i.e. \(C\) is active when both \(A\) and \(B\) are active. Yet, the ODE version recovers quantitative differences in \(C\) activity with values higher than 1. Notice that the exploration values for the ODE model is 11 values [0-10], while for a Boolean model is 2 (0 or 1).

7.2 Gene regulatory network

Now let’s move to a network model made of many individual regulatory interactions (Garcı́a-Gómez et al. (2020)). This model includes many regulatory interactions discovered for the cells of plant roots through years of experimental research. Here, all this knowledge is encoded as logical rules.

NoteFunction: Boolean network - Root 
def rootNetwork(parameters): 
    """Evaluate one synchronous update of the root gene-regulatory network.

    Args:
        parameters: Mapping of gene names (CK, ARR1, SHY2, AUXIAAR, ARFR,
            ARF10, ARF5, XAL1, PLT, AUX, SCR, SHR, MIR165, PHB, JKD, MGP,
            WOX5, and CLE40) to their current Boolean (0/1) values.

    Returns:
        Tuple of updated Boolean values in the same gene order listed above.
    """
    CK=parameters['CK']
    ARR1=parameters['ARR1']
    SHY2=parameters['SHY2']
    AUXIAAR=parameters['AUXIAAR']
    ARFR=parameters['ARFR']
    ARF10=parameters['ARF10']
    ARF5=parameters['ARF5']
    XAL1=parameters['XAL1']
    PLT=parameters['PLT']
    AUX=parameters['AUX']
    SCR=parameters['SCR']
    SHR=parameters['SHR']
    MIR165=parameters['MIR165']
    PHB=parameters['PHB']
    JKD=parameters['JKD']
    MGP=parameters['MGP']
    WOX5=parameters['WOX5']
    CLE40=parameters['CLE40']
    w_CK = (PHB and (1-ARFR) or (1-SHR))
    w_ARR1 = CK and (1-SCR)
    w_SHY2 = (1-AUX) and ARR1
    w_AUXIAAR = 1-AUX
    w_ARFR = 1-AUXIAAR
    w_ARF10 = (1-AUXIAAR) and (1-(JKD and SHR))
    w_ARF5 = (PHB or PLT) and (1-(SHR and MGP)) and (1-AUXIAAR)and (1-SHY2)
    w_XAL1= ARFR
    w_PLT= ARF5 or XAL1 or ARFR or WOX5
    w_AUX = 1
    w_SCR = SHR and SCR and JKD
    w_SHR = SHR
    w_MIR165 = (1-PHB) or (SCR and SHR and (1-ARR1))
    w_PHB = (((1-ARR1) and PLT) or PHB) and  (1-MIR165)
    w_JKD = (1-PHB) and SCR and SHR
    w_MGP = (1-ARF5) and SCR and SHR
    w_WOX5 = (1-ARF10) and ARF5 and (1-CLE40)
    w_CLE40 = 1-SHR
    return(w_CK,w_ARR1,w_SHY2,w_AUXIAAR,w_ARFR,w_ARF10,w_ARF5,w_XAL1,w_PLT,w_AUX,w_SCR,w_SHR,w_MIR165,w_PHB,w_JKD,w_MGP,w_WOX5,w_CLE40)

The model consists of 18 variables representing transcription factors, hormones, peptides. Look at the rootNetwork() function below. This function defines the state of 18 variables (CK, ARR1, SHY2, AUXIAAR, etc.) based on an input stored in parameters, then it updates the state of each variable using the logical operators \(AND\), \(OR\) and \(NOT\); the result is stored in w_variable. The function returns the update state w_variable for each of the 18 variables.

Time course simulation

To solve this Boolean network we have to first define an initial condition for each of these 18 variables, and then update their state using the logical functions stored in rootNetwork. We will repeat this updating for a given number of time steps (timesteps). This network has a total of 2^18 initial conditions, we are going to explore one of them at random by initializing the state of the variables with 0 or 1. First, we need to input the initial condition of the variables to rootNetwork() using parameters. Next, we save the output of this function as the new current state. We repeat this procedure iteratively for as many time steps as we defined, saving in a matrix the time course of the simulation. This can be done using a for loop as shown in the function TimecourseSimulation:

NoteFunction: timecourse simulation (remember to call it in the Execution part of the code) 
def TimecourseSimulation(network="synchronous",initial_condition=None):
    """Simulate and plot the root gene regulatory network over time.
    Inputs: network: Update scheme, either "synchronous" or "asynchronous".
        initial_condition: Optional sequence of 18 binary values specifying
            the starting state in network-variable order. If None, a random
            binary initial state is generated.
    Outputs: Displays the Boolean timecourse heatmap and saves it to
        'output/1-boolean-IC-timecourse.png'. Returns None.
    """
    
    update_functions = {
        "synchronous": rootNetwork,
        "asynchronous": rootNetworkAsynchronous,
    }
    if network not in update_functions:
        raise ValueError('network must be "rootNetwork" or "RootNetworkAsynchronous".')
    update_network = update_functions[network]

    timesteps=20
    variables=18
    # Create the timecourse matrix for the updating of the Boolean network. The first row stores a random 
    # binary initial state for all 18 variables, and each subsequent row is obtained by updating the
    # network from the previous state according to the logical rules encoded in rootNetwork().
    # This simulates how the gene regulatory network evolves over time from a random starting point.
    matrix = np.zeros((timesteps+1, variables), dtype=int)
    if initial_condition is None:
        matrix[0,:] = np.random.randint(0, 2, size=variables)
    else:
        initial_condition = np.asarray(initial_condition)
        if initial_condition.shape != (variables,) or not np.isin(initial_condition, [0, 1]).all():
            raise ValueError("initial_condition must contain exactly 18 binary values (0 or 1).")
        matrix[0,:] = initial_condition
    for i in range(timesteps):
        # Pass the current state of all variables to the update function so it can compute the next
        # state of the network based on the Boolean rules.
        parameters= {'CK': matrix[i,0], 'ARR1': matrix[i,1], 'SHY2': matrix[i,2], 'AUXIAAR': matrix[i,3], 'ARFR': matrix[i,4], 'ARF10': matrix[i,5], 'ARF5': matrix[i,6], 'XAL1': matrix[i,7], 'PLT': matrix[i,8], 'AUX': matrix[i,9], 'SCR': matrix[i,10], 'SHR': matrix[i,11], 'MIR165': matrix[i,12], 'PHB': matrix[i,13], 'JKD': matrix[i,14], 'MGP': matrix[i,15], 'WOX5': matrix[i,16], 'CLE40': matrix[i,17]}
        # Save the updated Boolean state for the next time step in the matrix.
        matrix[i+1, :] = update_network(parameters) # Save the output in i+1
    plotBooleanTimecourse(matrix,timesteps)

def rootNetworkAsynchronous(parameters):
    """Perform one probabilistic asynchronous update of the root gene network.

    Each node independently has a 95% chance of being updated according to
    its Boolean regulation rule; otherwise, its current value is retained.

    Args:
        parameters: Mapping of current Boolean (0/1) values for CK, ARR1,
            SHY2, AUXIAAR, ARFR, ARF10, ARF5, XAL1, PLT, AUX, SCR, SHR,
            MIR165, PHB, JKD, MGP, WOX5, and CLE40.

    Returns:
        Tuple of updated values, ordered as CK, ARR1, SHY2, AUXIAAR, ARFR,
        ARF10, ARF5, XAL1, PLT, AUX, SCR, SHR, MIR165, PHB, JKD, MGP, WOX5,
        and CLE40.
    """
    CK=parameters['CK']
    ARR1=parameters['ARR1']
    SHY2=parameters['SHY2']
    AUXIAAR=parameters['AUXIAAR']
    ARFR=parameters['ARFR']
    ARF10=parameters['ARF10']
    ARF5=parameters['ARF5']
    XAL1=parameters['XAL1']
    PLT=parameters['PLT']
    AUX=parameters['AUX']
    SCR=parameters['SCR']
    SHR=parameters['SHR']
    MIR165=parameters['MIR165']
    PHB=parameters['PHB']
    JKD=parameters['JKD']
    MGP=parameters['MGP']
    WOX5=parameters['WOX5']
    CLE40=parameters['CLE40']
    # With 0.5 probability, set w_CK as before, otherwise set to 0
    if np.random.rand() < 0.95:
        w_CK = (PHB and (1-ARFR) or (1-SHR))
    else:
        w_CK = CK

    if np.random.rand() < 0.95:
        w_ARR1 = CK and (1-SCR)
    else:
        w_ARR1 = ARR1

    if np.random.rand() < 0.95:
        w_SHY2 = (1-AUX) and ARR1
    else:
        w_SHY2 = SHY2

    if np.random.rand() < 0.95:
        w_AUXIAAR = 1-AUX

    if np.random.rand() < 0.95:
        w_ARFR = 1-AUXIAAR

        w_PLT = ARF5 or XAL1 or ARFR or WOX5

    if np.random.rand() < 0.95:
        w_AUX = 1
    else:
        w_AUX = AUX

    if np.random.rand() < 0.95:
        w_SCR = SHR and SCR and JKD
    else:
        w_SCR = SCR

7.3 Cell differentiation – jumping from one attractor to another

Whether a continuous or a discrete model is better, depends on the question we want to answer. To study the logic of cell differentiation, a Boolean model might be more appropriated particularly if we want to study the role of many genes, but lack details of the parameters underlying each reaction. Alternatively, if we wish to study the role of quantitative information in how cells change from one cell fate to another, a continuous model might be more appropriate.

Here you will learn how to convert a Boolean model into a continuous one and use it to predict which regulators are able of causing a change in the state of the system (changes in cell fate!)

Exercise 7.10 (Coding) One approach to keep the parameters in control is to use a “fuzzy logic” approach. We need to define a sigmoidal function, with a \(w_i\) term that represents the logical function of each node:

\(\frac{dX_i}{dt}=\frac{-e^{0.5h}+e^{-hw_i}}{(1-e^{0.5h)(1+e^{-h(w_i-0.5)}})}-dX_i\)

To translate the logical functions we replace an \(AND\) operator with a \(min\), and \(OR\) operator with a \(max\), and a \(NOT\) operator with a \(1-regulator\). See the code below implementing the ODE version of the root network we studied before. For most nodes the logical rule has been translated in \(w_node\). Translate yourself the remaining nodes. Compare the code of the functions rootNetwork() and rootNetworkODE().

NoteFunction: Root Network, ODE version 
def rootNetworkODE(a, t, parameters):
    """
    Compute the time derivatives for the root developmental gene regulatory network.

    This function evaluates the ODE system used to model interactions among root
    cell identity regulators. It combines regulatory weights using
    a sigmoid transfer function and subtracts decay terms for each variable.

    Inputs
    ------
    a : array-like. Current state vector containing the values of all model 
        variables in the order: [CK, ARR1, SHY2, AUXIAAR, ARFR, ARF10, ARF5, 
        XAL1, PLT, AUX, SCR, SHR, MIR165, PHB, JKD, MGP, WOX5, CLE40].
    parameters : dict
        Dictionary containing the model parameters, including:
        - 'decayrate': degradation/decay constant for each variable.
        - 'h': steepness parameter controlling the sigmoid response.
    Outputs
    -------
    A tuple with the derivatives for each state variable in the same order as
    the input vector.
    """
    decayrate = parameters['decayrate']  # decay rate
    h = parameters['h']  # this controls the shape of the sigmoid function
    CK=a[0]
    ARR1=a[1]
    SHY2=a[2]
    AUXIAAR=a[3]
    ARFR=a[4]
    ARF10=a[5]
